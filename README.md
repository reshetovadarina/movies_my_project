# Movie Wishlist 🎬

Сучасний модульний веб-додаток для створення персонального списку бажаних фільмів із можливістю інтеграції та пошуку у світовій базі кінематографа OMDb API.

## 📱 Демонстрація (Скриншот)

https://github.com/reshetovadarina/movies_my_project/blob/main/Movie_Wishlist.png

## ⚡ Можливості додатку

- Керування вішлістом: Додавання фільмів вручну із зазначенням назви, року випуску, жанру та статусу перегляду.
- Інтеграція з OMDb API: Асинхронний пошук фільмів у світовій базі за назвою (англійською мовою) із динамічним виведенням обкладинки (постера), оригінальної назви та року.
- Збереження з API: Можливість миттєво додати знайдений через OMDb фільм до свого локального списку бажань.
- Стійкий стан (State): Автоматичне збереження та відновлення списку фільмів і обраної теми за допомогою `localStorage`.
- Кібербезпека (XSS Safety): Повний захист від шкідливого коду завдяки безпечному наповненню DOM через `textContent`.
- Адаптивний дизайн (Responsive): Інтерфейс повністю оптимізовано під мобільні екрани, планшети та десктопи за допомогою CSS Flexbox та медіазапитів (`@media`).
- Доступність (Accessibility / A11y): Семантичні підписи `<label>` для всіх полів форми та чітке контрастне підсвічування фокусу при навігації клавішею `Tab`.
- Нічний режим (Dark Mode): Плавне перемикання між світлою та темною темами.

## 🛠️ Стек технологій

- **HTML5** (Семантична доступна верстка)
- **CSS3** (Custom Scrollbars, Transitions, Media Queries)
- **Vanilla JavaScript** (Чистий JS без сторонніх бібліотек)
- **ES6+ Modules** (Модульна архітектура проекту)
- **OMDb API** (Світова база даних фільмів)

## 📂 Структура проекту

- `index.html` — Семантичний каркас сторінки та форми без інлайн-стилів.
- `style.css` — Глобальні стилі, адаптивні медіазапити, анімації та класи темної теми.
- `script.js` — Головна точка входу, яка ініціалізує додаток та запускає старт програми.
- `events.js` — Обробники подій клавіатури (`Enter`) та миші, які зв'язують модулі докупи.
- `state.js` — Ізольоване керування масивом даних, захищене зчитування JSON та робота з `localStorage`.
- `render.js` — Відмальовування елементів інтерфейсу, карток фільмів, тостів та індикаторів завантаження в DOM.
- `api.js` — Модуль для виконання асинхронних мережевих запитів (`fetch`, `async/await`) до OMDb.
- `movies.js` — Початковий дефолтний масив фільмів для першого старту додатку.
- `helpers.js` — Допоміжні загальні утиліти (генерація унікальних ID, форматування рядків, функція `debounce`).
- `validation.js` — Чисті логічні перевірки форми на дублікати фільмів та коректність року випуску.

## 🚀 Як запустити проект локально

### ⚠️ Важливе зауваження щодо запуску:

Проект не можна запустити простим подвійним кліком миші по файлу `index.html` у провіднику комп'ютера.
Оскільки додаток побудовано на ES-модулях (`type="module"`), браузер заблокує завантаження сусідніх файлів (`events.js`, `state.js` тощо) за політикою безпеки CORS (Cross-Origin Resource Sharing), видавши помилку типу `Origin 'null' has been blocked`.

### 🛠️ Правильний запуск:

Проект необхідно запускати виключно через локальний веб-сервер.

1. Складіть усі файли в одну папку та відкрийте її у VS Code.
2. Встановіть розширення Live Server(від автора Ritwick Dey).
3. Натисніть правою кнопкою миші на файл `index.html` і оберіть Open with Live Server (або натисніть кнопку Go Live у правому нижньому кутку екрана).
